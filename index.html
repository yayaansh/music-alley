🎤 Karaoke

Karaoke version finds this song with the words on screen and the singer’s voice taken away. Words on screen turns on the video’s own lyric captions, when it has them.

🎙️ Dub it in…

Switches this video’s subtitles to the language you pick (✓ means the video has that language). A dub voice exists only when the video offers one under ⚙️ → Audio track.

Search settings (only needed if search ever stops working)
  1. On a computer, open Google Cloud: YouTube Data API, sign in with your Google account and click Enable (create a project if it asks).
  2. Go to Credentials → Create credentials → API key, then copy the key.
  3. Paste it here. It is saved only on this device.
